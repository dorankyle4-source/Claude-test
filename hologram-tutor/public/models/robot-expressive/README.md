# RobotExpressive

Model by [Tomás Laulhé (Quaternius)](https://www.patreon.com/quaternius), licensed **CC0 1.0**
(public domain). Facial morph targets added by [Don McCurdy](https://donmccurdy.com/).
Downloaded from the three.js repository (`examples/models/gltf/RobotExpressive`).

Used in Hologram Tutor as a free test model for the 3D model loader: it has a full skeleton,
14 animations (Idle, Wave, ThumbsUp, Yes, No, and others) and Angry/Surprised/Sad expressions.
